Paidline2 / 8

Product

A public board. First matching USDC claims it.

  1. List. Title, exact USDC, a small Creditcoin lock, a due date.
  2. Pay. Buyer sends USDC on Ethereum to the seller. Paidline never holds it.
  3. Prove. Anyone submits the Attestcoin proof. Precompile 0x0FD2 decides inclusion.
  4. Stamp. Match token, destination, exact amount. Emit InvoicePaid. Release the lock to the payer. isPaid becomes true.

The Creditcoin lock is a receipt bond, not the goods. The work is gated by isPaid or GET /api/gate/:id.

Paidline4 / 8

Surfaces

One checker. Four callers.

Sellers

Put a retainer, a seat, or an API credit on the board. Do not pick the buyer.

Buyers

Send USDC the way they already send it. No new chain to operate.

Agents

GET /api/gate/:id → 402 + pay URL. After the stamp, the same call returns 200.

Other contracts

isPaid(id) or InvoicePaid. They never integrate Attestcoin.
